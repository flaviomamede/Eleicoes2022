# Relatório de auditoria — entregáveis

| Arquivo | Formato |
|---------|---------|
| `auditoria_eleicoes_2022.md` | Markdown (fonte) |
| `build/auditoria_eleicoes_2022.html` | HTML **autocontido** (imagens embutidas em base64) |
| `build/auditoria_eleicoes_2022.pdf` | PDF |
| `figuras/` | Mapas e gráficos |

Regenerar figuras: `python3 ../scripts/gerar_figuras_relatorio.py`  
Regenerar HTML/PDF: `python3 build_html_pdf.py`
